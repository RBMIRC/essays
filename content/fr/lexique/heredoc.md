Notation Unix permettant d'encapsuler du texte multiligne dans du code exécutable — une façon d'incorporer des documents dans des programmes. Transformé dans le corpus en concept politique radical : le heredoc politique opère une triple mutation du code en instrument de contagion démocratique. Il est cartographie transparente de l'intention (le code montre ce qu'il fait), vecteur de contamination créative (il se propage par copie et modification), et nœud rhizomatique dans une architecture de savoir distribuée (chaque instance se connecte aux autres). Chaque fonction générée porte en elle les traces de sa généalogie collective. (*Heredoc Manifesto*)
