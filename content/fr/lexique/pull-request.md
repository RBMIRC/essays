Une proposition de modification dans le développement logiciel : « Voici les améliorations que j'ai faites dans mon fork, voudriez-vous les intégrer dans votre version ? » Le pull request formalise la relation entre le développement forké et l'autorité centrale, exigeant des mainteneurs qu'ils acceptent ou rejettent les modifications proposées. (*The Heredoc Manifesto*)
