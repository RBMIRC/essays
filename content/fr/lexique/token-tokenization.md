Le processus de fragmentation du texte ou du code en unités élémentaires (« tokens ») que l'algorithme manipule mathématiquement. C'est la première étape de la dissolution de l'intégrité sémantique — le code signifiant devient des vecteurs numériques, le préparant pour la compression statistique. La tokenisation commence la transformation de l'artefact auteuré en pattern statistique. (*The Heredoc Manifesto*)
