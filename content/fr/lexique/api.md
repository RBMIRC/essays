Interface standardisée permettant à différents composants logiciels de communiquer. Dans le contexte de l'IA, les API médiatisent l'accès aux capacités des modèles, créant une couche d'abstraction entre l'utilisateur et l'infrastructure computationnelle. Démocratise l'accès (n'importe qui peut appeler l'API) tout en centralisant le contrôle (le fournisseur définit les conditions). Les API transforment les capacités techniques en services consommables, obscurcissant la complexité matérielle sous-jacente.
