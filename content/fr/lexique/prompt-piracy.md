*Terme de l'Auteur* : intervention tactique transformant chaque requête API en accumulation primitive inversée. Quand un développeur génère du code via ChatGPT et le publie immédiatement sous GPL, il exproprie le capital pour construire des communs. Chaque prompt devient micro-expropriation, convertissant les ressources de l'entreprise en richesse collective. Non pas du vol (le code était déjà nôtre, encodé dans les poids entraînés sur la production collective) mais libération — réclamation de ce qui fut enclos. (*Heredoc Manifesto*)
