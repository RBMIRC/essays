Terme de Rasheedah Phillips (Black Quantum Futurism) : apprendre à décoder les mécanismes par lesquels le temps est volé, prédéterminé, colonisé — et les défaire. Non seulement une compétence analytique (comprendre comment les régimes temporels fonctionnent) mais une pratique de réappropriation (inventer d'autres rapports au temps). La littératie temporelle inclut la reconnaissance de comment les systèmes prédictifs forclôsent les futurs, comment les récits historiques contraignent les présents, comment certaines populations se voient refuser la souveraineté temporelle. (*The Workshop as Form*)
