*Terme de l'Auteur* : la condition sous laquelle les communs statistiques opèrent avec pleine force matérielle — quand l'information est constitutive de l'instanciation matérielle. Dans les domaines où cela tient, la recombinaison au niveau informationnel produit une nouveauté fonctionnelle au niveau matériel. Les semences en sont l'exemple : la séquence génétique *est* l'organisme. Le code logiciel en est l'exemple : le code *est* le programme. Là où la condition constitutive tient, les communs statistiques ont un potentiel transformatif maximal. (*Ethics of the Statistical Commons*)
