Un système où la sortie revient affecter l'entrée. Dans la cybernétique de premier ordre (Wiener), la boucle permet l'autorégulation — le thermostat maintenant la température. Dans la cybernétique de second ordre (von Foerster, Maturana, Varela), l'observateur est inclus dans la boucle : les observations modifient le système, le système modifié modifie les observations. Le projet Retcon Black Mountain s'enroule sur lui-même en boucles successives — chaque itération de recherche, atelier, documentation alimentant la suivante, chacune relançant les autres. (*Index*)
