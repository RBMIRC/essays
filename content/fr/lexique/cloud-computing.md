Ressources informatiques (stockage, traitement, services) accessibles à distance via les réseaux. Amazon Web Services, Google Cloud, Microsoft Azure dominent. « Le cloud » obscurcit l'infrastructure matérielle : centres de données consommant de l'électricité, systèmes de refroidissement, câbles à fibre optique, utilisation des sols. Centralise le contrôle tout en distribuant l'accès. L'entraînement et l'inférence de l'IA sont de plus en plus dépendants du cloud. Le Stack de Bratton théorise le cloud comme couche géopolitique. La métaphore de l'immatérialité dissimule une extraction et une consommation d'énergie très matérielles.
