Le processus par lequel les modèles apprennent en ajustant itérativement des milliards de poids pour minimiser l'erreur. Le Manifeste Heredoc souligne le coût écologique massif de cette transformation du savoir — l'énergie consommée pour convertir le code écrit par des humains en distributions statistiques. L'entraînement est le processus industriel par lequel le code privé devient des communs statistiques. (*Le Manifeste Heredoc*)
