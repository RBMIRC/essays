*Terme de l'Auteur* : la capacité de produire ce qui est nécessaire indépendamment de ce qui advient dans la sphère numérique. Prioriser les domaines où l'instanciation ne requiert que des moyens low-tech : les semences plutôt que les médicaments (les semences s'autorépliquent ; les médicaments requièrent de la chimie industrielle), les archives papier plutôt que les bases de données numériques (le papier survit sans électricité), les réseaux paysans plutôt que l'accès API (les relations humaines persistent quand les plateformes échouent). L'objectif n'est pas seulement les communs numériques mais l'indépendance vis-à-vis de systèmes qui peuvent être enclos ou fermés. (*Ethics of the Statistical Commons*)
