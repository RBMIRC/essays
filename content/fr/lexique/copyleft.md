Mécanisme de licence garantissant que les dérivés de productions collectives restent collectivement disponibles. Utilise le droit d'auteur contre lui-même : vous pouvez utiliser, modifier et distribuer, mais vous devez étendre les mêmes libertés aux autres. Fondamental pour les communs statistiques : la prépondérance du code sous licence GPL dans les données d'entraînement de l'IA crée ce que l'Auteur appelle la « valence différentielle » — une orientation éthique encodée dans les poids eux-mêmes.

**Références :**
- STALLMAN, Richard. "Copyleft: Pragmatic Idealism." Dans *Free Software, Free Society*. Boston: GNU Press, 2002.
- KELTY, Christopher M. *Two Bits: The Cultural Significance of Free Software*. Durham: Duke University Press, 2008.
