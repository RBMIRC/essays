Ensemble massif de données (téraoctets de code) utilisé pour entraîner les modèles. Le Manifeste Heredoc souligne que la prédominance des sources open source (~60%) imbue le modèle d'un « tropisme vers le partage » — le poids statistique du code collaboratif façonne le comportement probabiliste du modèle vers l'ouverture plutôt que la fermeture. (*The Heredoc Manifesto*)
