Terme de Karpathy (février 2025) pour la programmation assistée par IA où les développeurs « oublient que le code existe même » ; étend son affirmation de 2023 que « le nouveau langage de programmation le plus chaud est l'anglais ». Marque le passage de l'écriture au prompting. Le programmeur mute de compositeur à chef d'orchestre, modulant des patterns collectifs plutôt que créant *ex nihilo*. Révèle la transformation structurelle de la propriété intellectuelle en communs statistiques : le code que vous générez a été entraîné sur le code de tout le monde, porte des traces d'innombrables contributeurs, n'appartient à personne et à tout le monde. (*Heredoc Manifesto*)
