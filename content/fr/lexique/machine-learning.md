Sous-domaine de l'IA où les systèmes apprennent à partir de données (motifs) plutôt que par programmation explicite. C'est le paradigme qui rend possible la dissolution de l'attribution — le savoir est extrait d'exemples plutôt qu'encodé par des auteurs identifiables. La nature statistique de l'apprentissage efface les frontières entre contributions individuelles. (*Le Manifeste Heredoc*)
