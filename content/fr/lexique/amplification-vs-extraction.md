*Terme de l'Auteur* opposant les logiques extractivistes (cf. le Colonialisme des données de Couldry/Mejias) ; diriger l'attention vers les sources plutôt que de les absorber dans de nouvelles productions. Contrepoint méthodologique à l'appropriation. L'amplification reconnaît la dette envers les sources tout en les transformant ; l'extraction efface cette dette dans la production de nouvelles valeurs.
